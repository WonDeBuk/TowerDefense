# Game Assets

This directory contains all the game assets organized in the following structure:

## Directory Structure

- `textures/` - All game textures and images
  - `towers/` - Tower sprites and animations
  - `enemies/` - Enemy sprites and animations
  - `ui/` - UI elements and icons
  - `maps/` - Map textures and backgrounds
  
- `fonts/` - Game fonts
  
- `sounds/` - Sound effects
  - `towers/` - Tower-related sounds
  - `enemies/` - Enemy-related sounds
  - `ui/` - UI and menu sounds
  
- `music/` - Background music tracks

## File Naming Convention

- Use lowercase letters and underscores
- Include size/resolution in texture filenames (e.g., `tower_basic_64x64.png`)
- Include animation frame numbers (e.g., `enemy_walk_01.png`)
- Use descriptive names that indicate the purpose/content
